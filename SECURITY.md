# Security Policy

## Supported Versions

Project Rock is currently under active development.

Security improvements are continuously incorporated as the platform evolves.

---

## Reporting Security Issues

If you discover a security vulnerability, please avoid creating a public GitHub issue.

Instead, contact the project maintainer privately until a fix has been prepared.

---

## Security Principles

Project Rock follows:

- Least Privilege
- Infrastructure as Code
- Security by Default
- Zero Hardcoded Secrets
- Continuous Improvement

---

## Secrets

Secrets should never be committed to Git.

Approved mechanisms include:

- GitHub Secrets
- AWS Secrets Manager
- Ansible Vault
- Environment Variables

---

## Dependencies

Dependencies should remain updated and regularly reviewed for known vulnerabilities.
