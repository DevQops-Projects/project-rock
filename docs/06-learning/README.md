# Learning Notes

## Purpose

This directory serves as a personal knowledge base built while developing Project Rock.

Unlike feature documentation, these notes are organized by technology rather than by task.

Each document captures:

- Concepts learned
- Best practices
- Common mistakes
- Debugging experiences
- Design decisions
- Real-world implementation examples

## Philosophy

Whenever a new concept is learned during development, update the relevant technology document.

For example:

- React → Hooks, State Management, Routing
- TypeScript → Interfaces, Generics, Utility Types
- FastAPI → Routing, Dependency Injection, Middleware
- Docker → Images, Containers, Networking
- Kubernetes → Pods, Services, Deployments
- AWS → EC2, IAM, VPC, S3
- Terraform → Providers, Modules, State Management
- Git → Branching, Rebasing, Cherry-picking

Over time, these notes become a comprehensive engineering reference that can be used for revision, interview preparation, and onboarding.
