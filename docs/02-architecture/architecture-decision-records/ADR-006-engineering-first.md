# ADR-006

## Title

Adopt an Engineering-First Development Strategy

---

## Status

Accepted

---

## Context

The primary objective of Project Rock is to develop practical expertise in DevOps, Cloud, Platform Engineering, and modern software delivery practices.

Building a feature-rich application is a secondary objective.

---

## Decision

Engineering quality takes precedence over application complexity.

Application features should primarily exist to justify infrastructure, automation, deployment, monitoring, and security decisions.

---

## Consequences

### Advantages

- Stronger DevOps portfolio
- Practical cloud engineering
- Better understanding of production systems
- Lower infrastructure cost
- Faster learning

### Trade-offs

- Slower application feature development
- Smaller MVP

---

## Future Considerations

As engineering maturity increases, application functionality will evolve naturally while preserving engineering quality.
