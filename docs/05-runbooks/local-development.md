# Local Development Runbook

## Purpose

This runbook describes how a developer sets up and works with Project Rock locally.

---

# Development Workstation

Primary environment:

- Ubuntu 24.04 LTS

Secondary environment:

- Windows (documentation and productivity)

---

# Repository

Clone using SSH.

Feature branches are required for all development.

---

# Local Stack

Future local development uses:

- Docker Compose
- PostgreSQL
- FastAPI
- Next.js

---

# Standard Workflow

1. Pull latest changes
2. Create feature branch
3. Implement changes
4. Test locally
5. Update documentation
6. Commit
7. Push
8. Open Pull Request
9. Merge
10. Delete feature branch

---

# Definition of Ready

Before implementation:

- Documentation reviewed
- Environment ready
- Dependencies installed
- Business requirement understood

---

# Definition of Done

A task is complete when:

- Code implemented
- Tests pass
- Documentation updated
- Security reviewed
- Pull Request merged
