# Contributing to Project Rock

Thank you for your interest in contributing to Project Rock.

Project Rock follows production-inspired engineering practices. Every contribution should improve either the platform, documentation, infrastructure, or learning experience.

---

## Development Workflow

1. Fork or clone the repository.
2. Create a new branch.
3. Implement your changes.
4. Update documentation if required.
5. Test your changes.
6. Open a Pull Request.

---

## Branch Naming

Examples:

feature/user-authentication

feature/terraform-network

bugfix/login-api

docs/update-readme

chore/dependency-upgrade

---

## Commit Messages

Use Conventional Commits whenever practical.

Examples:

feat:

fix:

docs:

refactor:

test:

ci:

chore:

---

## Pull Requests

Every Pull Request should include:

- Business Context
- Summary of Changes
- Testing Performed
- Documentation Updates
- Checklist Completion

---

## Engineering Standards

Before submitting:

- Documentation updated
- No secrets committed
- Code formatted
- Tests passing
- Meaningful commit history

---

Thank you for helping improve Project Rock.
